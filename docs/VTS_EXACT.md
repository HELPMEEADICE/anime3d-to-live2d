# VTS 性能版的后续无损优化

本次以此前交付的 `POPY_VTS_Performance` 为基准，**不新增画质损失**。原有有损拟合的动作误差仍保留，本轮不是恢复最初高质量模型。旧模型不覆盖，交付 `delivery/POPY_VTS_Exact.zip`。

## 实现与等价性边界

只合并作者顺序中相邻且父变形器、纹理页、剔除方式、遮罩列表、反转标记、参数轴、逐关键形排序/透明度和全部 BlendShape 标量程序完全相同的 ArtMesh。位置数据按顶点拼接、索引加固定偏移，UV 原值拼接。它们的排序函数完全相同，稳定排序时不会有第三个原网格插在相邻成员之间。每个顶点仍经过原来的浮点插值、残差叠加和父变形器运算，没有移除参数轴或重新拟合。

**任何被用作遮罩来源的网格都不合并。** 这样既不扩大其他上下文的覆盖区域，也不改变遮罩 alpha 并集的绘制次序。合并后的目标包含原目标的相同顶点，遮罩上下文边界仍为同一顶点并集。单网格限制 60,000 顶点，避免超出原生 16-bit 索引范围。

随后复用现有 `moc_pack`：按原始 IEEE float32 位模式复用位置块和颜色行；通过未修改运行时公开 API 记录主关键形与 BlendShape 的完整读取范围，只去掉不可读取的尾部填充。没有量化、删三角形或缩小贴图、遮罩。独立 MIT 程序处理几何与存储，独立 GPL 导出进程沿用此前许可边界。

## 本机结果

| 指标 | 前一性能版 | 后续无损版 |
|---|---:|---:|
| MOC 字节 | 108,735,616 | 89,307,200 |
| ArtMesh | 3,998 | 2,800 |
| 主 ArtMesh 关键形 | 129,677 | 111,255 |
| 顶点 / 三角形 | 173,000 / 195,441 | 完全保留 |
| Glue | 0 | 0 |
| Deformer / 最大深度 | 2 / 2 | 2 / 2 |
| CPU Driver 中位 | 3.072 ms | 2.373 ms |
| 参数设置至 GPU 完成中位 | 51.787 ms | 33.825 ms |
| GPU 同指标 P95 | 58.794 ms | 38.602 ms |
| 同一 362 姿态渲染进程峰值 RSS | 817.37 MiB | 532.84 MiB |

RTX 5080 Laptop GPU，原生 DX12，未修改 Ayagami `0d1d7aa3efe57b1b363b72e672e353c52a9c15d6`。CPU 与 GPU 分别交替执行 4 轮同一 60 姿态，每模型预热 5 帧，各 240 个计时样本；两模型同时驻留。GPU 含提交和同步，不含 PNG 下载写盘。峰值 RSS 是前后分别运行同一 362 姿态的进程采样，不是多轮统计。桌面未隔离，**不代表 VTube Studio 实机 FPS 或内存**。

本轮姿态集合与上一轮 12 姿态性能记录不同，不能用上轮 29.1 ms 和本轮 33.8 ms 做跨实验结论；表内前后采用相同输入、设备和测量程序。文件缩小约 17.9%，ArtMesh 减少约 30.0%，CPU 中位耗时下降约 22.7%，完整渲染中位耗时下降约 34.7%，本次峰值 RSS 下降约 34.8%。

## 质量证据

- 1,803 姿态，311,919,000 次原始顶点比较，**位模式零差异**，包括隐藏遮罩。独立 Rust 工具用每个原网格到新网格连续片段的映射检查 UV、索引、材质、遮罩、深度、透明度和颜色。
- 362 姿态全分辨率 RGBA **逐像素零差异**，包含实际渲染排序与遮挡结果。
- 纹理、参数显示信息、58 个动作、24 个表情及运行时资源引用的字节摘要相同；39 个参数范围、默认值、类型相同。80 个遮罩上下文和牙齿修复保留。
- 参数几何检查包含连续单轴扫描、固定随机组合、原回归及 58 个动作采样。数值结果、输入/模型/映射摘要见 `benchmarks/popy/fullbody/vts_exact.json`，本地完整证据在 `artifacts/vts_exact/`。

有限姿态测试不是连续参数空间的穷尽证明；等价性依据同时包含前述未改变逐顶点浮点程序、稳定排序和遮罩来源的结构约束。没有 Cubism Core、Editor 或 VTS 实机验证；无新增 CMO3。部分 ArtMesh ID 合并，用户之前逐 ArtMesh 设置的 VTS 特效/外观可能需要重设；参数、动作、表情 ID 保留。

## 复现

需要本机上一性能版、对应 IR、固定依赖、JDK 和回归用例；公开仓库不分发角色资产。先按原项目说明构建 GPL 导出器，再运行：

```powershell
cargo build --release --locked --manifest-path rust/Cargo.toml -p popy-validate --bins
python -m popy.vts_exact all
```

可分阶段运行 `rig|export|validate|report|package`；打包阶段要求几何和图像检查零差异、资源摘要相同，拒绝不满足条件的候选。VTS 安装目录同前，仍在 Live2D Mask Config 选择 256 masks、每组至少 512×512。
