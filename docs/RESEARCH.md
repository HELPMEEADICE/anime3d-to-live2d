# 已落实的技术决策

## 数据与拟合

审计来源为真实 bpy 场景：14 Mesh、30,514 顶点、51,288 三角形、233 根骨骼，原始资产有两个 UV 层，眉毛/脸/眼睛具备不同的真实 Shape Keys。外部贴图路径失效，但 16 张源图已打包，其中六张 albedo 被直接提取。全部骨骼绑定矩阵、逐顶点权重和未选用的 morph 也被导出，供继续研发。

转换的对应关系是原始三角形 corner → 源顶点 + loop UV。UV seam 拆点，三角形拓扑保留，原始 triangle IDs 和顶点 IDs 存在每个 ArtMesh 的 source 字段。可见网格仍使用源顶点；遮罩裁片支持真实三角形重心坐标插值，并对所有关键形与 BlendShape 复用同一映射，没有执行通用重拓扑。

拟合把真实 Blender 求值作为基准。局部参数支持来自实际 morph 位移，不通过 PNG alpha 轮廓猜网格。主表情在每个头部姿态采样差分；相对 Shape Keys 和线性蒙皮允许同一姿态内差分叠加，并由独立组合参考渲染验证。身体 yaw 与 Head 子树的组合利用骨骼层级的线性变换分解，再投影。它不同于二维平移。

原生 Rotation Deformer 承担头/身体 roll；ArtMesh 网格只保存三维非交换旋转、蒙皮和表情的残差。这样改善未见过的 roll 姿态，避免把旋转弦线误认为视觉合理的线性插值。两个 Warp 承担归一化投影/呼吸，层级最深三层。没有声称完成通用非线性 FFD 控制点优化、Jacobian/Laplacian 正则化或局部自交修复。

组合规模通过三角形实际影响签名分区控制。完整参数空间不做笛卡尔积；只对影响同一个小块的头部/身体 yaw、pitch/局部表情构造格点。平衡版将身体 pitch 作为 BlendShape，复杂组合产生约 30.8 px 的 RMSE；实测后增加质量版 3×3 身体联合基，再投影头部和局部表情，解决这一严重误差。附加笑眼仍是 neutral-head BlendShape。

## 遮挡与连续性

同一套源纹理与拓扑保留了正面隐藏的侧脸、耳部、头发等真实表面。输出按有限训练域的包络裁掉始终不参与投影的几何，额外考虑身体姿态；不是多视角序列帧。没有执行多视角光照纹理烘焙或生成隐藏面补图，因为本资产已具备原生 UV 与打包贴图。

Cubism 可原生表达固定三角形、参数关键形、Warp/Rotation、参数 opacity、drawOrder、clip masks、Glue、BlendShapes。它没有三维 z-buffer、透视深度、运行时拓扑替换或自动暴露新顶点。本轮新增由真实前方皮肤/前发表面构造的反向眼部遮罩；背部皮肤虽然可能投影进眼洞，但不应参与遮挡，因此按 morph/gaze 包络保守裁切。眼白、瞳孔采用稳定层次，禁止 gaze 深度残差穿过该层次。遮罩、普通 ArtMesh 和参数均由实际 MOC3 在 Ayagami 中求值验证。

Rust 在 384×512 的每个投影采样上找真实前表面，构建“远块必须在近块前绘制”的覆盖约束。对循环保留删除诊断，以共享参考、双端最近排序投影与参数格点邻域平滑控制连续性；全局不活跃约束必须弱于当前姿态真实深度。针对24个高冲突块保留源三角形并局部细分，配置记录源几何指纹，避免错误复用于新资产。这仍是明确近似，不能保证所有交叉表面和连续角度的拓扑变化正确。

分块边界采用原生 Glue。只有位置、完整权重及所有 morph 差分一致的同对象顶点才可焊接，避免把几何邻近但动画不同的顶点误合并。MOC 网格关键形改存绝对父空间坐标，避免大画布 rest 与 delta 的 float32 相消。质量版以少量原生 Warp 曲线及头部旋转原点曲线补偿身体 pitch 中间值的弦缩，保留未恢复深度/yaw 交叉项的限制。

新增165个深度眼部参考姿态、70对相邻帧，包含转头/俯仰/倾斜连续扫描。眼部诊断用真实深度渲染的白色眼球对比，源同一性接缝测量与alpha缺口分别统计。时域残差减去真实运动，但仍混有几何插值和边缘偏差，不能直接称作离散排序跳变数量。

## 导出与验证

PSD2Live 的 RigIR/中立 MIT 模块可作为交换格式参考；真实格式写入仍经过 GPL Umamo。为了保持来源映射、采样诊断和深度优化，本项目先用自己的小型文件 IR，再直接创建 PuppetModel，调用 `Moc3Export`、`Moc3.write` 与 `Cmo3Conversion.freshCmo3`，没有运行 PSD2Live 默认二维自动绑定，也不需要 PSD。

目标为 Cubism 5.0（MOC3 版本字节 5、CMO3 对应 writer profile）。MOC3 实际由独立的 Ayagami 解析、参数求值、GPU 渲染。平衡版 CMO3 经过写入器自身的读回检查，未找到可用官方 Editor 安装，因此官方编辑继续使用能力仍未证实。质量版的 CMO3 在 7 GiB 和 10 GiB Java 堆中均发生 `OutOfMemoryError`；保留约 216 MB 的真实质量版 MOC3，与配套平衡版工程分别交付。CMO3 的 source art 由纹理页裁片构造，上游会报告 `MissingSourceArt`；它不是原作者分层 PSD，保留的可编辑结构仍需 Editor 验证。

图像参考统一采用 emission/albedo、同一投影矩阵、768×1024、透明背景。另有原 MToon 材质渲染供人工审阅，**不能用 albedo 回归结果声称保留了 MToon 动态光照或轮廓线**。

测试包括训练端点、非训练连续值、左右独立眨眼、眼球跟随、嘴形、眉毛、复合头身和所有极值。几何误差对照 Blender 另行求值的源顶点，包含被遮挡的顶点；图像指标包括前景 MAE、Gaussian SSIM、alpha IoU、轮廓距离。方向翻转计数只统计和同姿态真实投影方向不一致的三角形，正常 3D 背面翻转不被当作算法错误。

## 后续优先级

1. 在已实现的冲突块细分上，进一步优化边界与交叉处的局部遮罩，按误差合并无冲突块以减少 draw calls。
2. 用局部低秩深度基或局部 deformer 层级压缩身体 pitch 与头转的联合基；质量版已表达该耦合，但密集局部关键形的体积和编辑器导出内存成本过高。
3. 对网格残差做关键形/轴退化检测与压缩。当前为兼容导出保留完整局部格点，模型仍偏大。
4. 局部 screen Jacobian/可见轮廓权重的重拓扑与误差驱动补采样；普通像素 MAE 不足以衡量眼睑细节。
5. 导入 Cubism Editor，检查源图/atlas 模式、参数点、绘制顺序、保存与重新导出，再进行官方 runtime 差分验证。
6. 为真实头发骨链增加独立残差基、physics3 和时序回归；本轮没有完成这项功能。
